# Jekyll Portfolio Starter

A one-page Jekyll portfolio for GitHub Pages with placeholder projects and skills.

## 1) Rename the repository
For a personal site, use:

`yourusername.github.io`

## 2) Replace placeholders
Edit:
- `_config.yml`
- `_data/profile.yml`
- `_data/skills.yml`
- `_data/projects.yml`

## 3) Local preview
Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open the local address shown in the terminal.

## 4) Publish with GitHub Pages
Push the repo to GitHub, then go to:

**Settings → Pages → Build and deployment**

Set the source to **Deploy from a branch** and choose the `main` branch and `/ (root)` folder.

## 5) Add media
Put project screenshots in:
`assets/images/`

Then update the image paths in `_data/projects.yml`.
